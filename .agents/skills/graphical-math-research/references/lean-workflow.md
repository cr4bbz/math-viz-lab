# Lean workflow

Read this reference when adding, changing, or citing a formal claim.

1. Translate the claim without strengthening what the visual evidence supports.
2. Separate exceptional parameter values before cancellation or division.
3. Prefer a classification theorem (`↔` or set equality) that directly explains
   the visual fiber over isolated existence lemmas.
4. Add a distinctness theorem when a picture counts distinct points but the
   algebraic expression may contain repeated roots.
5. Do not use `sorry` for a claim recorded as `lean_proved`. Keep unproved claims
   in the manifest and notes as conjectures instead.
6. Run the manifest's Lean commands. Cite the exact theorem and source path only
   after a successful check.
7. If Lean refutes the proposed formulation, preserve the failed idea in the
   research notes only when it is mathematically instructive; otherwise correct
   the formulation without presenting the failed statement as evidence.
